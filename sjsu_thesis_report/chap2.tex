\chapter{Related Work}

\section{Distributed Reinforcement Learning}

Early research on Distributed Reinforcement Learning created the initial architecture that allowed training to be scaled. Using massively parallel methods, Nair et al.~\cite{nair2015} used actor-learners (parallel actors generating behavior) and learners (off-line parallel training using previously generated experience), and distributed neural networks; they achieved massive speedups on Atari games. The above method was further developed by Espeholt et al.~\cite{impala2018}, who presented IMPALA. They separated action generation from learning by utilizing importance sampling for off-policy corrections, allowing for scaling of thousands of machines with state-of-the-art performance as well as scalability across multi-task benchmarks. Horgan et al.~\cite{apex2018} also developed an additional architecture called Ape-X, which separated data collection and learning via distributed priority-based experience replay. In this, multiple actors generate experiences which are then stored within a single shared experience replay buffer. This is then accessed by the learner(s).

\section{Communication-Efficient Distributed Training}

The importance of reducing overhead on communication for distributed training has received a lot of attention. Chen et al.~\cite{chen2018} created new policy gradient methods for distributed reinforcement learning that can be used to create efficient ways to compress gradients so they cost less to communicate while still ensuring the algorithms will converge. Lin et al.~\cite{dgc2018}, working with distributed stochastic gradient descent, discovered that 99.9\% of all communications of gradients are unnecessary and proposed the technique Deep Gradient Compression (DGC), which can achieve bandwidth reductions from 270 to 600$\times$ using local gradient clipping and momentum corrections. More recently, Rahmati and Rahmati~\cite{bafrl2026} proposed BA-FRL, which combines reward-volatility-based communication triggering with Top-K gradient sparsification for federated RL, achieving up to 43\% communication reduction in multi-agent autonomous systems by having agents communicate only when learning is active and the network has capacity.

\section{Pipeline Parallelism for Large Models}

Huang et al.~\cite{gpipe2019} demonstrated how GPipe could effectively partition models into multiple accelerators and process mini-batches through different pipeline stages. They utilized micro-batching and gradient accumulation techniques to allow for nearly linear increases in performance when training models that were 25 times larger than what was possible on a single accelerator. Narayanan et al.~\cite{pipedream2019} demonstrated how PipeDream can automatically partition Deep Neural Networks (DNN) and schedule computations to reduce pipeline bubble time. PipeDream maintains many versions of model weights so that model weight updates can be performed continuously, without having to block for synchronization. In order to improve model parallelization in transformers, Shoeybi et al.~\cite{megatron2019} developed an efficient method of intra-layer model parallelism for Megatron-LM. This approach achieved 76 percent scaling efficiency using 512 GPUs to train a model with 8.3 billion parameters. Rajbhandari et al.~\cite{zero2020} introduced ZeRO by removing the need to store redundant copies of optimizer state, gradients, and model parameters across all data-parallel processes.

\section{Resource-Constrained Environments}

Recent work addresses distributed learning in resource-constrained settings. Lim et al.~\cite{lim2020} applied federated learning principles to RL for IoT devices, enabling multiple agents to collaboratively learn optimal control policies while keeping data local, addressing device-specific dynamics variations. Feng et al.~\cite{feng2023} designed IoTSL, an efficient split learning system for resource-constrained IoT devices, optimizing the split learning paradigm to handle non-IID data distribution and reduce communication requirements specific to IoT constraints.

Our work differs from prior approaches by specifically addressing the communication bottleneck in pipeline-parallel on-policy DRL training through selective gradient accumulation. While existing gradient compression techniques focus on compressing all gradients uniformly or through quantization, our approach accumulates gradients over time and transmits only high-magnitude values above configurable percentile thresholds, tailored to the unique characteristics of on-policy DRL training with repeated epochs.
